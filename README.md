# BuilderSpace 😎

> **Bring an idea. Make it work.**
> 带上想法来，一起搞定。

从 UNSW 起步的中英双语创客社团。这个仓库是我们的官网：活动、项目广场、会员卡和活动现场工具都在这里。

总之就是一个让「我有个点子」变成「我做出来了」的地方。我们的经验是，中间通常隔着几杯咖啡和一个队友。

## 见见 The Five Sparks

网站整体用黑、白、镀铬三种颜色，彩色留给了这五位：

- 🩷 **Vivi** 知微 · 探索者：_What if…?_
- 💛 **Lumi** 灵犀 · 灵感家：_I've got an idea!_
- 💙 **Geo** 格物 · 研究者：_Let's figure it out._
- 💚 **Momo** 青禾 · 实践家：_Let's build it!_
- 💜 **Kiko** 同舟 · 协作者：_Together, we can!_

加入时选一只，会印在你的会员卡上哦。

## 技术栈

Next.js 16 · Supabase · Vercel。首页的液态金属和一万七千多个粒子拼成的吉祥物，都是手搓的 WebGL。

## 跑起来

```bash
pnpm install
cp .env.example .env.local   # 不填 Supabase 也能跑，页面显示示例数据
pnpm dev                     # http://localhost:3000
```

提交前请跑 `pnpm check`。CI 跑的也是它，所以本地先跑一遍能少挨一次 CI 的批评。
