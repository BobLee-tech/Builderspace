个人网站提示词

挑一个风格，填好你的信息，页面会把整段提示词拼好。复制，粘贴给 AI，就能拿到你的第一版网站。

  1. 1选风格
  2. 2填信息
  3. 3复制提示词
  4. 4部署上线
第 1 步

选一个风格

这些只是参考。先和同桌聊聊你想要什么感觉，也可以去小红书、Google、X 上搜「个人网站」「作品集网站」「portfolio website」，看看别人做成什么样，挑一个最适合、最喜欢的。

找到了就用最后一张「用我自己找到的网站」。

下面 18 个都是网上真实的开源个人网站，截图是它们原本的样子。挑一个你喜欢的，提示词会让 AI 复刻它，把内容换成你的信息。点「看大图」里的「AI 做的」，能看到 AI 照着它一次做出来的效果；不满意就用最下面的话术一句句改。

你填的内容只留在这个页面里，不会上传给任何人。刷新还在，关掉页面就没了，记得存一份到备忘录。网站做好后谁都能打开，所以只写你愿意公开的内容。

第 2 步

填你的信息

现在填的是示例（虚构的同学「许安然」），复制前换成你自己的。

中文名、英文名都行，也可以两个都写。
会放在名字下面。例：UNSW 商科二年级，喜欢拍照和做小工具
写 2–3 句：你是谁、在学什么、接下来想做什么。
写 3–6 个，用逗号或顿号隔开。
作品或经历 1–3 个，每个一句话。有链接就贴上，没有就空着，网站上就不放「查看」按钮。
联系方式 只写愿意公开的，不想写的空着。

第 3 步

复制提示词

下面就是会被复制的全文，可以检查一下
拿到第一版以后

想改哪里，一次发一句

第一版不会和原站一样好。AI 一次生成的效果，很难直接达到原网站的质感，这很正常。接着在同一个对话里多聊几轮：说清楚哪里不像、想要什么效果，也可以把原网站的截图发给它对比，一点点打磨，越改越好。

一次只改一件事，改完看一眼再发下一句。方括号里的换成你想要的。

    最后一步

    部署上线，发给大家看

    改满意了，在同一个对话里发这段，让 AI 把网站放到 GitHub Pages。仓库用 GitHub 默认的个人主页仓库「用户名.github.io」，网址就是 https://用户名.github.io，免费、不用买域名。

    还没有账号就先去 github.com 注册一个，用户名会出现在你的网址里。
