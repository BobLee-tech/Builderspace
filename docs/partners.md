# 合作伙伴：确认挂名后怎么放上官网

合作伙伴出现在三个地方：

- 首页「合作伙伴」：项目广场之后、吉祥物之前。还没有合作方时只放一张邀请卡（Kiko），有了以后是 logo 墙，最后一行用「下一位合作方」空位补齐
- 活动页「本场支持」：在这场活动的成果下面，一行 logo。没有合作方时整行不出现
- 页脚「参与」栏的「合作」：一直都在，链到首页这一块

位置：

- 数据：`src/lib/partners.ts`，按加入顺序一条一条写
- logo：`public/partners/`
- 显示：`src/components/partners.tsx`，样式在 `src/app/partners.css`

## 步骤

1. **活动结束一周内**：对外合作逐家问挂名。确认四件事：显示名、角色（场地 / 工具额度 / 嘉宾 / 联合主办 / 物料）、放不放首页、官网链接。
2. **要 logo**：要深色背景用的彩色 SVG（带 `viewBox`），或者透明底 PNG。没有深色版的，别自己改颜色，改用对方确认过的文字版或者再去要。顺便问品牌主色（`#rrggbb`），用来做卡片背后的光晕。
3. **放文件**：logo 存成 `public/partners/<英文短名>.svg`（或 `.png`），打开看一眼黑底上清楚不清楚。只有带底色的深色版 PNG 时，可以只把底色抠成透明，logo 本身的颜色不动；PNG 裁到贴边，高 240px 左右就够。
4. **填数据**：在 `PARTNERS` 里加一条：`name` 按对方同意的写法原样写，`slug` 用英文短名（介绍的地址 `?p=<slug>`），`events` 填帮过的活动 slug，`since` 写第一次合作的学期（如 `T3 2026`）。只帮过一场的先只上活动页；长期合作再加 `home: true` 上首页。
5. **写介绍（可选）**：点开合作方卡片会弹出介绍，数据是 `intro`。我们按对方公开资料写，只写事实，每条一行：
   - 类型、所在地、一句定位、两三行「关于」、给成员带来了什么、每场活动里做了什么（`did`，按活动 slug）
   - 有对方同意公开的一句话才放 `quote`；没有官网时 `page` 放对方的公开主页（如 Humanitix）
   - 活动的标题、日期、名额从活动表读，到场人数从 `src/lib/event-results.ts` 读，不手填；没办的活动标「即将」，不算进数字
   - 写好发给对方确认，回复 OK 后填 `confirmed: "YYYY-MM-DD"` 才会上线。没填时只有 `pnpm dev` 看得到，底部标「草稿」
   - 不写：对方官网的营销句子、没到账的额度、联系人的邮箱和微信（除非对方说可以放）
6. **发版**：跑 `pnpm check`，测试会检查 logo 文件是否存在、颜色和学期格式、链接是不是 https、每条至少出现在一个地方。本地看一眼中英两种语言和手机宽度，开 PR。
7. **合作结束**：去掉 `home: true`，首页撤下，活动页的「本场支持」保留。

## 不上页面的情况

- 没确认的，包括「洽谈中」
- UNSW 和 Arc 不算合作方，不上合作伙伴墙；我们是 Arc 注册社团，要用 Arc 的标识按 Arc 给社团的规定来
- 「官方」「独家」「首个」这类字眼
- 改过颜色、拉伸或加特效的 logo，一律用原版
