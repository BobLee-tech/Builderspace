# 资料包：每场活动结束后怎么放上官网

资料包是一个用得上的页面 `/learn/<slug>`，不是一堆文件。资源页 `/learn`、活动页的结束卡片和活动列表都会链过去。

页面上有：

- 三条路：我想改网站（改网站提示词）、我从零开始（五步，能打勾）、我卡住了（按症状排错）
- Your kit：填一次 GitHub 用户名，直达链接和提示词都换成本人的；用户名、进度只存在访客浏览器里
- 存一张图：在浏览器里画一张竖版图，手机上弹分享，电脑上直接下载
- 成果墙入口，数字来自 `src/lib/event-results.ts`

位置：

- 数据：`src/lib/event-materials.ts`，按活动 slug 分段，中英两份
- 页面：`src/app/learn/[slug]/`（`workbench.tsx` 交互，`poster.tsx` 存图）

## 步骤

1. **活动后 24 小时内**：在 `event-materials.ts` 里给这场加一段。大多数内容可以照上一场改。文字一句一件事，不写成段的话。
2. **提示词**：链接和提示词里要换成用户名的地方写 `{u}`，要访客自己填的写成【…】（中文）和 […]（英文），页面会高亮。
3. **常见问题**：把当天 helper 遇到最多的卡点加进「我卡住了」，每条给两三步检查和一条能发给 AI 的提示词。
4. **讲义**：要放讲义，先出公开版：插画写上作者，去掉嘉宾联系方式、兑换码这类只在现场给的东西。
5. **发版**：跑 `pnpm check`，本地看一眼中英两种语言和手机宽度，开 PR。目标是活动后 48 小时内上线。

办活动用的方案、主持稿、嘉宾方案不放进资料包。
